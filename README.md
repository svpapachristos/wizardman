# wizardman
a small top-down movement prototype made in GameMaker.
Tile-based background, with a camera following a small wizard walking around a field, limiting the player to a confined grass area.
This project was a "dipping the toes into the water" moment for me and taught me that self learning coding is not as hard as it seemed and is actually super fun.
